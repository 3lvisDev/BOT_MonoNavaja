# Comandos de MonoNavaja Bot

Los comandos de barra son la forma recomendada de utilizar el bot. Discord muestra las opciones requeridas al escribir cada comando.

Los comandos de música y ayuda están publicados globalmente. Las funciones de radio, playlists, tickets, emojis y AutoMod se publican actualmente en el servidor configurado para la comunidad.

## Música

| Comando | Acción |
| :--- | :--- |
| `/play query:<búsqueda o URL>` | Reproduce música desde una búsqueda o enlace. |
| `/stop` | Detiene la reproducción actual. |
| `/skip` | Salta la canción actual. |
| `/next` | Alias de `/skip`. |
| `/previous` | Vuelve a la canción anterior. |
| `/pause` | Pausa la reproducción. |
| `/resume` | Reanuda la reproducción. |
| `/queue` | Muestra la cola actual. |
| `/radio accion:<on, off, status o reset>` | Controla el modo radio; acepta un género o artista opcional. |

## Playlists

| Comando | Acción |
| :--- | :--- |
| `/playlist_create` | Crea una playlist. |
| `/playlist_list` | Lista las playlists disponibles. |
| `/playlist_add` | Añade una canción por búsqueda o URL. |
| `/playlist_play` | Reproduce una playlist. |
| `/playlist_import` | Importa contenido desde una URL o URI de Spotify. |

## Tickets

| Comando | Acción |
| :--- | :--- |
| `/ticket_open` | Abre un ticket con un título. |
| `/ticket_list` | Lista tickets abiertos, cerrados o todos. |
| `/ticket_close` | Cierra un ticket por ID. |

## Emojis

| Comando | Acción |
| :--- | :--- |
| `/emoji_add` | Añade un emoji desde una URL. |
| `/emoji_delete` | Elimina un emoji por nombre. |
| `/emoji_list` | Lista los emojis personalizados del servidor. |
| `/emoji_app_list` | Lista los emojis de la aplicación. |
| `/emoji_use` | Devuelve un emoji de aplicación o un texto alternativo. |

## AutoMod

| Comando | Acción |
| :--- | :--- |
| `/automod_status` | Muestra el estado de AutoMod. |
| `/automod_enable` | Activa AutoMod. |
| `/automod_disable` | Desactiva AutoMod. |
| `/automod_word_add` | Añade una palabra bloqueada. |
| `/automod_word_remove` | Elimina una palabra bloqueada. |
| `/automod_word_list` | Lista las palabras bloqueadas. |

## Utilidad

| Comando | Acción |
| :--- | :--- |
| `/help` | Muestra la ayuda general. |

La disponibilidad puede variar mientras Discord propaga una actualización de comandos globales.
