## Funciones principales

| Función | Qué puedes hacer |
| :--- | :--- |
| **Música en voz** | Buscar y reproducir música o enlaces de Spotify y YouTube. |
| **Radio inteligente** | Mantener la reproducción con un género o artista como referencia. |
| **Reproductor web** | Consultar y controlar la reproducción desde el panel. |
| **Playlists** | Crear, importar y reproducir listas personalizadas. |
| **Tickets** | Abrir, consultar y cerrar solicitudes de soporte. |
| **AutoMod** | Activar reglas y gestionar palabras bloqueadas. |
| **Emojis** | Añadir, listar, usar y eliminar emojis del servidor o la aplicación. |

## Empieza a usarlo

1. Abre la [invitación oficial](https://panel.monoconavaja.xyz/invite).
2. Selecciona un servidor en el que tengas permiso para añadir aplicaciones.
3. Revisa los permisos solicitados y completa la autorización de Discord.
4. Entra a un canal de voz y utiliza `/play` con una búsqueda o URL.

Si quieres revisar el flujo antes de autorizar el bot, visita la
[página de instalación](https://panel.monoconavaja.xyz/install).

## Comandos esenciales

| Comando | Acción |
| :--- | :--- |
| `/play` | Reproduce música por búsqueda o URL. |
| `/radio` | Activa, desactiva o consulta el modo radio. |
| `/skip` | Pasa a la siguiente canción. |
| `/queue` | Muestra la cola de reproducción. |
| `/playlist_list` | Muestra las playlists disponibles. |
| `/ticket_open` | Abre un ticket. |
| `/automod_status` | Consulta el estado de AutoMod. |
